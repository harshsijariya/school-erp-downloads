# School ERP Android downloads

Official Student and Teacher Android apps for the School ERP hosted at **https://school.gahoiparinay.com**.

- [Download Student APK](https://github.com/harshsijariya/school-erp-downloads/releases/download/v1.0.3/school-student-1.0.3.apk)
- [Download Teacher APK](https://github.com/harshsijariya/school-erp-downloads/releases/download/v1.0.3/school-teacher-1.0.3.apk)
- [SHA-256 checksums](https://github.com/harshsijariya/school-erp-downloads/releases/download/v1.0.3/SHA256SUMS)

Requires an Android phone running Android 6 or newer. Download the APK, allow installation from your browser when Android prompts, then sign in with the account issued by your school. The Student app accepts student and parent accounts; the Teacher app accepts teacher and class teacher accounts.

The school website and API are live at https://school.gahoiparinay.com. Sign in using the account issued by your school.

Student features include attendance, timetable, homework, assigned teachers, notices, date sheets, results and leave requests. Parent accounts also access child-specific fees. Teachers can request leave and class teachers can review student leave in the app and web portal. Attendance uses Present, Absent and Leave tick buttons. Teacher features depend on assigned classes, subjects and permissions.

This public repository distributes signed APKs and checksums. It does not contain school data, backend source, credentials or signing keys.

Version 1.0.3 adds private homework file attachments. Teachers upload files for assigned classes; students and linked parents can open, download and share them. The school website now has a compact student directory and a three-step admission form with optional private photos and office-only documents.
